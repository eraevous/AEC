# Addendum to spec 004 (2026-11-04)

Spec 004 stays frozen and unedited. Its data contract defines `sha256` as the digest of the whole
file. Spec 006 (`specs/006-ledger-hygiene/spec.md`, authorized by Zach on 2026-11-04 as C-09,
DEC-048) adds, without changing that default:

- an optional anchor field `prefix_bytes`, which makes `sha256` the digest of the file's first
  `prefix_bytes` bytes (its length when anchored);
- an optional `append_only` list in `.aec/sources.json`, under which whole-file anchors are also
  checked against newline-ended prefixes of the current file;
- a sixth state, `appended`: the file grew, and begins with exactly the anchored bytes. Like
  `verified`, it is not a finding; it is labelled separately in `check` and `source show`.

A grown file is still `mismatch` for any anchor outside those two opt-ins (fixture P8-2 unchanged).
