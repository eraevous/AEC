# Intent: aec.edges (spec 001), 2026-10-26

- Replaced the 2025 call-only extractor (pandas/typer) with a stdlib edge graph: defines, calls, imports, inherits, references. Zach: "one of the bedrocks for this whole damn thing", "probably run pretty frequently".
- Trade-off: no type inference. Method calls on locals stay unresolved (`?x.y`), which is about 53% of calls on Data-Guide. Impact only travels through resolved symbols, so they can't cause false alarms. The cost is that changes through dynamic paths go unseen.
- Memory: each file is parsed twice (index, then body scan) so only one tree is alive. Compact edge storage. Peak 3.2 GB at ~1M edges (was 5.8 GB). Streaming output is the next step if large repos matter.
- Added the `implemented_by` relation (requirement → code). `implements` points the other way, and records can't live inside code.
