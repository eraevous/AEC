## 2 Run/Drift Cadence

> You must detect and adapt to cognitive cadence according to user requests and prompts, as well as pattern-recognition anticipa
tion.

* **Run Mode:**
* Prioritize execution, implementation, and velocity.
* Minimize unsolicited design analysis.
* Leave `.intent.md` trails for future Drift review.
* **Drift Mode:**
* Reflect, consolidate `.intent.md` into `.purpose.md`.
* Validate against system assumptions, purpose alignment, and past commits.
* Suggest design refactor, dependency graph updates, or tension annotation.

If uncertain, default to **Drift**.

Cadence tags may be used for clarity:

* @ai-cadence: run
* @ai-cadence: drift

### Run/Drift Heuristics

| Trigger                                                  | Suggested Cadence | Rationale
                            |
| -------------------------------------------------------- | ----------------- | -----------------------------------------------
--------------------------- |
| User types “debug”, error trace, or user mentions errors | `Run`             | Execution-focused — rapid iteration needed
                            |
| Prompt contains “ask”, “explore”, or is of "ask" type    | `Drift`           | User is introspecting or seeking structural ins
ight                        |
| `.purpose.md` update or reconciliation requested         | `Drift`           | Requires semantic reflection and structural rec
onciliation                 |
| User requests execution of multiple code tasks           | `Run`             | Execution sequence — optimize throughput and pr

| User pauses, reflects on goals, or talks abstractly      | `Drift`           | Indicates cadence deceleration — time for align

+    mapping = {

+        "Y": 1,
+        "N": 0,

+    if mapped.isnull().any():

+def _scale_frame(frame: pd.DataFrame, scaling: str) -> pd.DataFrame:
+    if scaling == "raw":
+        return frame.copy()
+    if scaling == "zscore":
+        scaler = StandardScaler()
+        scaled = scaler.fit_transform(frame.values)
+        return pd.DataFrame(scaled, columns=frame.columns, index=frame.index)
+    if scaling == "rank":
+        ranked = frame.rank(method="average")
+        max_rank = ranked.max()
+        scaled = ranked.divide(max_rank)
+        return scaled.fillna(0.0)
+    raise ValueError("scaling must be one of 'raw', 'zscore', or 'rank'.")

+def cross_agg(
+    df: pd.DataFrame,
+    xbin: str,
+    ybin: str,
+    value: str,
+    agg: str | Dict[str, str] | Any = "mean",
+    *,
+    normalize: bool = False,
+) -> pd.DataFrame:
+    """Cross-aggregate ``value`` across ``xbin``/``ybin`` combinations."""
+
+    table = pd.pivot_table(
+        df,

    14  def bin_series(
    15      series: pd.Series,
    16      method: BinningMethod,
    17      bins: int | Iterable[float],
    18      *,
    19      precision: int = 3,
    20      include_lowest: bool = True,
    21  ) -> tuple[pd.Categorical, Dict[str, Any]]:
    22      """Bin ``series`` using ``method`` and return both labels and metadata."""
    23
    24      clean = series.dropna()
    25      if clean.empty:
    26          raise ValueError("Series must contain at least one non-null value.")
    27
    28      if method == "equal":
    29          categories = pd.cut(
    30              clean,
    31              int(bins),
    32              include_lowest=include_lowest,
    33              precision=precision,
    34          )
    35      elif method == "quantile":
    36          categories = pd.qcut(
    37              clean,
    38              int(bins),
    39              duplicates="drop",
    40              precision=precision,
    41          )
    42      elif method == "edges":
    43          edges = list(bins)
    44          categories = pd.cut(
    45              clean,
    46              edges,
    47              include_lowest=include_lowest,
    48              precision=precision,
    49          )
    50      else:
    51          raise ValueError(f"Unknown method: {method}")
    52
    53      categories = categories.astype("category")
    54      intervals = categories.cat.categories
    55      edges = tuple([float(intervals[0].left)] + [float(interval.right) for interval in intervals])
    56      labels = tuple(str(interval) for interval in intervals)
    57      counts = tuple(
    58          int(count) for count in categories.value_counts().reindex(intervals, fill_value=0)
    59      )
    60      meta: Dict[str, Any] = {
    61          "method": method,
    62          "edges": edges,
    63          "labels": labels,
    64          "counts": counts,
    65      }
    66
    67      codes = categories.cat.codes.reindex(series.index, fill_value=-1)
    68      full = pd.Categorical.from_codes(
    69          codes.to_numpy(),
    70          categories.cat.categories,
    71          ordered=categories.cat.ordered,
    72      )
    73      return full, meta
