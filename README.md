# AEC

AEC/Codex++ is an experiment in **AI-native software scaffolding**:  
a framework where codebases remember their intent, contracts, and cadence —  
so AI coding tools like OpenAI’s Codex can act as collaborators, not autocomplete.

Core principles:
- `.purpose.md` → module contracts (inputs, outputs, role, risks)
- `.intent.md` → transient design reasoning
- `AGENTS.md` → repo-level behavioral constitution
- Run/Drift cadence → explicit rhythm for execution vs reflection

This repo is both a **reference implementation** and a **testbed**  
for using Codex as a co-architect, not just a code generator.
